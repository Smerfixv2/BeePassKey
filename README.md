# 🐝 BeePassKey

> Simple, secure and fully customizable password manager.

BeePassKey is a simple and modern password manager designed to securely store passwords and other sensitive login information in one place.

## Features

- Secure password storage
- Encrypted password vault
- Fully customizable interface
- Custom themes
- Fast search
- Add passwords
- Edit passwords
- Delete passwords
- Password categories
- Easy password copying
- Custom settings
- Password generator
- Simple and user-friendly interface

## Built With (will be)

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- SQLite
- Cryptography
